# Topic Copy Pack · 选题全量文案包

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Version](https://img.shields.io/badge/version-1.3.0-blue.svg)](VERSION)

> 一个选题进去，四平台成品、一篇结构化飞书文档、一份 HTML 引流资料一起出来。

---

## 它解决什么问题

同一件事，要写成口播稿、广播稿、公众号长文、小红书图文，大多数人是在一份稿子上改四遍。结果是四个平台都像同一个人的同一篇文章：视频不抓人，广播不陪人，公众号没论证，图文没干货。

本 Skill 的做法是：**把四个平台当成四种文体，分别成稿，再装进同一副文档骨架；文案里承诺的那份资料，同步做成可离线打开的 HTML 实物。**

---

## 核心特性

| 特性 | 说明 |
|---|---|
| **一题四稿** | 口播视频、广播音频、公众号软文、种草图文，各自独立结构 |
| **固定文档骨架** | 章节名、编号、层级一字不改，四平台对齐可比 |
| **平台规则内置** | 字数区间、钩子位置、节奏、结尾动作，写死在规范里 |
| **引流合规硬校验** | 视频/小红书零站外引流，只有公众号/广播站可导私域 |
| **知识卡片规范** | 6–9 张 3:4，筛选→拆解→模板→验收→总表→行动 |
| **公众号一节一画板** | 6–8 节的长文，每节正文下方嵌一张真正可再编辑的飞书画板（SVG），不是配图 |
| **引流资料同交付** | 文案承诺的《XX手册》落成单文件 HTML，断网可读、手机可看、可打印 |
| **内嵌两个写法库** | 公众号接 `doubao-wechat-writing`（类型/排版/运营策略/内容验真），种草接 `doubao-note-creator`（笔记结构/配图/标签互动），不重写方法论 |
| **公众号运营件齐全** | 备选标题 5 条、封面方案、内容验真 4 项、运营策略 6 条，一起进文档 |
| **交付前自检** | 脚本校验字数、节数、画板数量与结论条、封面、卡片数、违规词、AI 味硬禁词、资料名与关键词一致性，不合格不交付 |

## 各平台体量（v1.3.0）

| 平台 | 字数 | 说明 |
|---|---|---|
| 口播视频 | 800–1000 | 约3分钟，只讲一个点 |
| 广播音频 | 1900–2100 | 约8分钟，三个场景各讲透 |
| 公众号 | 1400–1600，6–8 节 | 每节 150–300 字，一节一张画板 |
| 种草图文 | 280–350 ＋ 6–9 张卡 | 评论区关键词，零站外 |

初稿一律过 `doubao-human-signal`（去 AI 味）再进文档。

## 设计哲学

1. **骨架固定，内容自由。** 结构统一才能批量生产，也才能对比优劣。
2. **承诺必须兑现。** 评论区扣【关键词】领的资料，必须是能打开、能照着做的实物。
3. **四种文体，不做四份改写。** 口播靠钩子，广播靠陪伴，公众号靠论证，图文靠卡片。
4. **合规写进脚本。** 靠提醒守不住，靠校验才守得住。
5. **没跑通就说没跑通。** 不编数据、不编案例、不编身份。
