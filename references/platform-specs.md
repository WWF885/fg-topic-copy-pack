# 四平台文体规范（核心）

四个平台是四种文体，不是一份稿改四遍。同一母题，四个入口、四种节奏、四套结尾。

## 一、字数与时长速查

| 平台 | 正文字数 | 折合时长 | 硬阈值（脚本拦） |
|---|---|---|---|
| 口播视频（long） | 800–1000 | 约3分钟 | 800–1000 |
| 口播视频（short） | 240–300 | 约60秒 | 240–300 |
| 广播音频 | 1900–2100 | 约8分钟 | 1900–2100 |
| 公众号正文 | 1400–1600（目标1500） | 阅读5–7分钟 | 6–8节，每节150–300，合计1350–1650 |
| 公众号摘要 | 60–110 | — | 50–120 |
| 公众号画板 | 6–8张，一图一句结论≤12字 | — | 6–8张，SVG 文件须存在 |
| 种草发布文案 | 280–350 | — | 260–380 |
| 知识卡片 | 6–9张，每张80–140 | — | 6–9张 |
| 各平台发布文案 | 150–220 | — | 140–240 |

**口径变更记录**：口播由 900–1150 下调为 800–1000（讲透一个点，不注水）；广播由 1000–1250 上调为 1900–2100（伴随收听需要更长的铺垫与场景）；公众号由六节固定改为 6–8 节、目标 1500 字（不再为凑节拆段）。

## 二、口播视频

**体量**：800–1000 字，约 2.5–3 分钟。只讲一个点，讲透；宁可少一条方法，不靠形容词凑字数。

**结构（7段，缺一不可）**

1. 钩子（5–15秒）：一个决定、一个反常识、一个具体现象。**禁止**"大家好，我是XX"
2. 立论：把钩子翻译成一句判断，全片只围绕这一句
3. 自证：一段真实身份/经历，交代"我凭什么讲这个"
4. 拆解：把抽象词落到具体场景——以前怎么做、卡在哪、现在怎么换
5. 方法：3–4步，每步一句动作，能照着做
6. 升华：一句金句收束，不喊口号
7. CTA：只引导评论区关键词

**语言**：一句一个意思，一段不超过3行；多用"你有没有过""我举个自己的例子"；不用"首先/其次/最后"，不用长定语。

**60秒切片版**：钩子（3秒）→ 现象三连（20秒）→ 一句判断（10秒）→ 一个方法（20秒）→ 评论关键词（7秒）。只讲一个点，不铺背景。

## 三、广播音频

**体量**：1900–2100 字，约 8 分钟。公众号与口播可以省略的铺垫，广播不能省——听众是半专注状态，必须靠场景把人拉住。

**结构（10段）**

1. 痛点三连问（"你有没有过这样的感觉……"），**先戳痛点，不先自我介绍**
2. 报节目名：`欢迎收听本期的《AI旅者广播站》，我是王文锋。`
3. 自述身份：一段，不超过三句
4. 抛出命题：今天想和你聊什么
5. 场景一：讲透一个细节，可带一句对话或一个具体时间
6. 场景二：和场景一形成对照（以前/现在、别人/自己）
7. 场景三：把代价写清楚——不变会怎样
8. 认知转折：从"解决问题"到"改变流程"这类一层翻转
9. 一句可记住的话：全篇只留一句，重复一次
10. 收尾：`这里是《AI旅者广播站》，感谢你的收听，我们下期再见。` + 公众号关键词

**2000 字怎么分配**：开场约 250 字，三个场景各 350–400 字，转折约 250 字，方法与金句约 300 字，收尾约 100 字。每个场景必须有具体名词（时间、地点、动作），否则删掉重写。

**双主持版（小艾 + 文锋）**：小艾抛问题、做总结；文锋给判断、给方法。开场仍由痛点起，第二段才报节目名和两位主持人。

**听觉友好硬要求**：不能出现"看下图""表格里"；数字口语化并重复一次；避开同音歧义（"全部/全不"）；每2–3段用过渡句（"后来我发现""说到这"）。

## 四、公众号软文

**体量**：1400–1600 字，目标 1500；**6–8 节**，不再固定六节——素材够就拆到七、八节，不够就压到六节，禁止为凑节把一段拆成两段。

**节次分工（前六节固定，七/八节按素材可选）**

| 节 | 任务 | 字数 |
|---|---|---|
| 01 | 一个判断或一个现场，把读者拉进来 | 180–220 |
| 02 | 拆现象：为什么明明不忙却很累 | 200–260 |
| 03 | 认知转折：从"用工具"到"建系统/换方式" | 200–260 |
| 04 | 方法一：可执行，给动作与验收 | 220–280 |
| 05 | 方法二：反例与代价，把边界划清 | 220–280 |
| 06 | 落地：一页清单或 7 天计划 | 180–240 |
| 07（可选） | 常见误区三条：每条一句"你以为/其实是" | 180–240 |
| 08（可选） | 写在最后：收束主张，不喊口号 | 150–200 |

**语言**：书面但不端着，允许长句；每节开头先给判断，再给依据；段与段之间必须有承接词。标题写成判断，不写成名词短语。

**标题**：≤20字，观点型或悬念型，不用疑问句堆叠，不用"震惊/必看"。

**引流**：全文只导一次，放在最后一节自然带出"关注公众号 AI旅者王文锋，回复关键词领取"。

### 4.1 每节必须配一张画板（看板技能）

公众号不是"文字＋配图"，而是**每节正文下方嵌一张逻辑画板**，让读者在扫读时先看懂结构，再读字。

| 项 | 规则 |
|---|---|
| 载体 | 飞书**画板（whiteboard）**，SVG 生成后以 `<whiteboard type="svg" path="@./wb-0X.svg"/>` 嵌入该节正文 `<p>` 之后 |
| 图型 | 只允许三种：**结构图**（流程/层级/对照）、**证据图**（场景分屏、前后对比）、**清单图**（勾选项/一页表） |
| 张数 | 一节一张，6–8 节对应 6–8 张；不配图的节只允许是最后的引流节 |
| 文字 | 图题写判断句；节点用"动词＋对象"；每图仅一条 ≤12 字结论条，其余为标注 |
| 配色 | 深藏蓝 `#2A5D8F` 主色 + 极浅底 `#F4F7FA` + 细线 `#DEE3E8`，反差色仅标关键判断 |
| 尺寸 | 16:9（1600×900）或 4:3（1200×900），正文宽度 820px 内可读，最小字号 14px |
| 禁止 | 风景图、人物合影、emoji 堆砌、纯文字截图、与本节论证无关的装饰图 |
| 发布 | 飞书文档里嵌 whiteboard；发到公众号后台时导出 2× PNG，插在同一位置（公众号编辑器不认飞书画板） |

**画板与文字的分工**：文字负责论证与情绪，画板负责结构与对照。画板里不重复正文原句，只把正文那一段的关系抽出来（谁→谁、几步→几步、错→对）。

## 五、种草型图文

**发布文案结构（6段）**

1. 钩子：`别再……了，真正值得……的是……`
2. 身份背书：一句，带年限/行业
3. 承诺：这套内容能帮你解决什么
4. 分点步骤：4条，每条一个 emoji 起句，一条一个动作
5. 行动：先跑通一个小场景，别贪多
6. 收束 + 评论关键词

**标题3条备选**：都≤20字，一条给结果、一条给人群、一条给方法。

**知识卡片是主体，不是配图**：7张的经典分工是 封面 → 筛选标准 → 流程拆解 → 可复制模板 → 验收清单 → 一页总表 → 7天行动。详见 `card-specs.md`。

**语言**：口语、短句、能直接抄；emoji 每段最多1个；不自称专家，用"我正在试""亲测有用"。

## 六、引流合规矩阵（最容易被判违规的地方）

| 平台 | 可导流去向 | 允许话术 | 一律禁止 |
|---|---|---|---|
| 口播视频 | 站内评论区 | `评论区扣【关键词】` | 公众号、微信、加V、链接、"主页有" |
| 种草图文 | 站内评论区 | `评论区留言【关键词】` | 公众号、微信、私信发你、二维码 |
| 公众号 | 公众号自身 | `关注公众号 AI旅者王文锋，后台回复关键词` | 诱导分享、外链导流 |
| 广播音频 | 公众号 | `关注公众号 AI旅者王文锋，回复关键词` | 留私人微信、电话 |

**判断口诀**：站内平台只谈"评论区"，私域平台才谈"公众号"。

## 七、四篇都要过去 AI 味（强制）

四篇初稿写完后，逐篇调用 `doubao-human-signal` 改写，只改说法不改事实与数据。口播、广播这两篇是"要被读出声音"的，必须过；公众号、种草同样过。

| 项 | 要求 |
|---|---|
| 禁用词 | 首先／其次／此外／值得注意的是／综上所述／赋能／闭环／生态／底层逻辑 |
| 句式 | "不是 A 而是 B" 每篇≤1 次；连续破折号与概念引号清零 |
| 段落 | 段尾禁升华；每段至少一个具体名词（时间、地点、动作、数字口径） |
| 口播／广播加测 | 朗读一遍，凡是读着要换气三次以上的句子，拆开 |
| 准出 | 自评≤30 分；无编造数字；开头三句里不出现"大家好，我是" |
| 顺序 | 先写完再改，改完**重新计字数**，以终稿为准；别为凑字数把改好的句子再加回去 |

## 八、四平台差异化对照

| 维度 | 口播视频 | 广播音频 | 公众号 | 种草图文 |
|---|---|---|---|---|
| 接收状态 | 刷到，3秒定生死 | 伴随收听，半专注 | 主动打开，愿读长文 | 搜索+逛，看图为主 |
| 人称 | 我（对你说） | 我/我们（陪你） | 我（与你共勉） | 我（姐妹/同类） |
| 情绪浓度 | 高 | 中，舒缓 | 中，克制 | 中高，共情 |
| 信息密度 | 每10秒一个点 | 每30秒一个点 | 层层递进 | 卡片承载 |
| 结尾动作 | 评论关键词 | 关注公众号 | 关注公众号 | 评论关键词 |
