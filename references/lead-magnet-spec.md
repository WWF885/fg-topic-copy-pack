# 配套引流资料（HTML）规范

四平台文案里承诺的那句“评论区扣 【关键词】，我把《XX手册》发给你”，**必须有实物**。这份实物就是单文件 HTML 资料页：粉丝拿到链接或文件，打开就能照着做。

它不是广告页，也不是公众号文章的网页版。判断标准只有一条：**陌生人打开后，能不能靠自己把这件事做出第一步。**

## 一、命名与落位

| 项 | 规则 |
|---|---|
| 资料名 | 与文案承诺一致，格式 `《XX手册》/《XX清单》/《XX对照表》`，4–14 字 |
| 关键词 | 2–6 字，必须与口播、种草的评论区 CTA 完全一致 |
| 文件名 | `XTxxx_资料名.html`，如 `XT009_超级个体能力搭建手册.html` |
| 落位 | 选题文件夹下新建 `05_引流资料/`，HTML 放进去；同一文件夹可放封面图与 PDF 导出件 |
| 登记 | manifest 增加 `lead` 板块（name / keyword / path / sections），校验脚本会核对 |

## 二、固定结构（七块，顺序不变）

| 块 | 内容 | 硬要求 |
|---|---|---|
| 01 页头 | 资料名 + 一句话主张 + 关键词标签 | 主张必须是判断句，不写“赋能/助力” |
| 02 速览 | 3–4 张卡，写清“这份资料能帮你解决什么” | 每张一个动作结果，不写目录复述 |
| 03 自测 | 3 个是非题 + 一句判语 | 让读者 30 秒内知道自己属于哪一类 |
| 04 方法主体 | 3–4 个能力或步骤，每个“是什么→怎么做→做到什么算对” | 每步给一个可执行动作，不写理念 |
| 05 可复制模板 | 1–3 段提示词/表格/清单，可整段抄走 | 单独文本框，等宽字体，便于截图 |
| 06 验收清单 | 3–5 条勾选项 + 一条辨错示例 | 必须能判断“合格/不合格” |
| 07 行动计划 | 7 天或 30 天，每天一个动作 | 留勾选位，不写“坚持就是胜利” |

页脚只放三行：资料出处（AI旅者王文锋 · 选题 XTxxx）、版本与更新日期、一句“本资料为经验整理，不构成专业建议”。

## 三、视觉规范

- 主色一套：深藏蓝 `#2A5D8F` 或墨绿 `#2F5D50`，反差色仅用于“关键判断”与“禁止项”
- 底色纯白，分组用极浅主色底 `#F4F7FA` + 1px 细线 `#DEE3E8`
- 正文 16–17px，辅助 14px，标题层级靠字号与字重，不靠彩色
- 手机优先：单列为主，两列仅用于对照表；卡片圆角 10px，间距 16px
- 打印友好：`@media print` 去掉底色与悬停，保证黑白可读
- 不放大面积深色块，不加装饰性渐变，不加自动播放动效

## 四、技术规范（会直接被平台转发，必须离线可用）

- **单文件自包含**：CSS 写 `<style>`、JS 写 `<script>`，不外链 `.css/.js`
- 不引用任何 CDN、字体、图片外链；需要图就用 CSS 画或 SVG 内联
- 中文用系统字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
- 体积 ≤ 800KB，首屏无需滚动即可读到“资料名 + 主张”
- 不埋统计脚本、不加跳转、不加“立即购买/扫码进群”
- 顶部加一句 `本页可离线打开，建议保存到手机`

## 五、文案红线

| 允许 | 禁止 |
|---|---|
| 页脚写“资料出处：AI旅者王文锋” | 页内出现二维码、微信号、加群、私信我 |
| 写“完整版在公众号回复关键词” | 写“转发三个群才能领”“限时 24 小时” |
| 引用自己真实经历 | 编数据、编案例、编他人头衔 |
| 标注“经验整理，不构成专业建议” | 医疗、法律、收益类给出结论性断言 |

## 六、交付前检查

1. 资料名与四平台文案里承诺的名字逐字一致
2. 关键词与口播、种草的 CTA 逐字一致（校验脚本会拦）
3. 用手机打开，不横向滚动，首屏能读到主张
4. 断网打开仍然完整（无外链资源）
5. 打印预览黑白可读
6. 文件已放进 `05_引流资料/`，链接已回填到交付说明
