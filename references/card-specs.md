# 知识卡片规范（种草图文的主体）

卡片不是配图，是主体。用户收藏的是卡片，不是文案。

## 一、硬规则

1. 数量 **6–9 张**，常规 7 张；统一 **3:4**，按阅读顺序编号 `卡01｜`
2. 每张必须能**脱离正文单独阅读**：有标题、有结论、有可执行动作
3. **禁止**把正文缩短、摘几句金句贴上去；必须重新组织信息
4. 单卡文字 **80–140 字**，一屏读完，手机字号下不挤
5. 不出现账号名、Logo、水印、二维码、"点击主页"
6. 每张只讲一件事，卡片之间是递进关系，不是并列堆料

## 二、7 张的标准分工

| 卡序 | 卡型 | 任务 |
|---|---|---|
| 卡01 | 封面卡 | 两行大字居中 + 一句副文案，说清"拿走什么" |
| 卡02 | 筛选卡 | 给判断标准，让读者自己勾选（如三列筛选表） |
| 卡03 | 流程卡 | 把一个动作拆成 3–4 格，每格一个动作 |
| 卡04 | 模板卡 | 可直接复制的提示词/句式，单独文本框 |
| 卡05 | 清单卡 | 3–5 条勾选式验收标准 + 一条辨错示例 |
| 卡06 | 总表卡 | 六字段一页总表（任务｜输入｜AI动作｜人工判断｜输出｜验收） |
| 卡07 | 行动卡 | 7 天行动清单，留可勾选位置 |

## 三、卡型库（按选题替换）

- **对比卡**：旧做法 vs 新做法，左右两栏
- **避坑卡**：3 个常见错误 + 正确做法
- **算账卡**：时间/成本前后对比（只用心算得出的真实数字）
- **关系卡**：谁把什么交给谁（人机分工）
- **自测卡**：5 题打分，判断自己处在哪一档

## 四、每张卡的书写格式（文档里就这么写）

```
卡01｜【卡名】
副文案：【一句利益点，可选】
【内容要点 80–140 字，可用 ①②③ 分点】
排版｜【版式说明：几行大字/几格流程/表格列数/文本框】
```

**排版说明要具体到可执行**：`两行大字居中`、`三列筛选表，标出优先项`、`四格流程，每格一个动作`、`单独文本框，便于截图复制`、`三条勾选项加一条辨错示例`、`七步清单，留勾选位`。

## 五、封面卡的两行字

- 每行 2–4 字，用"／"分隔，例：`AI提效／实操笔记`
- 两行是"领域／类型"，不是标题；标题交给发布文案
- 大字之下必须有一句副文案，否则读者不知道能拿走什么

## 六、常见返工

- 7 张全是金句 → 至少 4 张必须是表、流程、清单、模板
- 每张都在讲道理 → 每张结尾要有一个动作或一个判断标准
- 卡片之间重复 → 用"筛选→拆解→模板→验收→总表→行动"的递进链检查
- 文字塞满 → 删到 140 字以内，宁可少讲一点
