# 种草笔记写法（内嵌 doubao-note-creator）

小红书不是「短一点的公众号」，而是「封面卡 + 内页卡 + 纯正文 + 标签」的一整套笔记。本文件把上游技能的执行要点固定成骨架，不重复它的方法论文本。

## 二、一篇笔记的固定构成

1. **封面卡**：3:4，承接标题钩子，大字两行（每行 4–6 字），一图一钩子。
2. **内页卡 6–8 张**：一张一个要点，统一底色与字体，编号可见，能单独阅读、照着操作。
3. **正文 ≤1000 字符**：开头接标题，中段给细节，结尾给低成本动作；只保留自然段、emoji、轻量序号。
4. **标签 5–8 个**：核心词 2 + 人群词 1–2 + 场景词 1–2 + 相关热词 1，只用和内容真相关的。
5. **评论区引导**：一个关键词 + 一句轻动作（如「评论区留【手册】，我整理好的版本发你」），零站外、零私信、零二维码。

## 三、开头三秒的六种钩子（选一，不叠加）

价值承诺 / 冲突反差 / 结果前置 / 痛点场景 / 身份背书 / 求助气口。本 skill 默认用「痛点场景 + 结果前置」，因为要把方法卖给正在卡住的人。

## 四、五种骨架（选一条主线，别混）

痛点解决型（痛点→痛感加深→解法）｜种草转化型（苦恼→问题→尝试→变化→适合谁）｜干货教程型（为什么值得做→是什么→怎么做）｜测评对比型（先立标准→对比→适合/不适合）｜合集清单型（收藏价值→分类→取舍）。

本 skill 默认「干货教程型」；选题偏经验分享时用「痛点解决型」；六张以上卡片按「合集清单型」组织。

## 五、标题与正文的硬约束

- 标题 ≤20 字符，关键词前置，不用「震惊/必看」，承诺必须由正文兑现。
- 三条备选分别覆盖：结果型、人群型、方法型。
- 正文不写「第一、第二、第三」串段落，不用总分总；每段至少一个具体名词（时间、动作、数字口径）。
- 封面文字与标题不同义重复：标题讲冲突，封面给结论；标题给结论，封面给场景。

## 六、图片与合规

- 卡片统一 3:4、统一字重与留白；不写账号名、Logo、水印、二维码、平台标识。
- AI 生成的卡片在文档「素材与审核交接」里标注；不冒充实拍、不伪造聊天记录或后台截图。
- 站内平台只谈「评论区」，正文、标题、标签、置顶都不得出现「公众号」「微信」「加V」「私信」。
- 商业合作、医疗、金融、教育承诺类选题，按上游合规条目降级为经验分享，不给绝对化结论。
